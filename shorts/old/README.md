# Очередь «старых» шортсов со словами

Положите сюда MP4-файлы (GitHub → эта папка → Add file → Upload files).
Публикуются по алфавиту, через день с новыми уроками. Удобно называть `001_salam.mp4`, `002_kitab.mp4`…

Подписи (необязательно) — в `titles.json`:

```json
{"001_salam.mp4": "Слово дня: سلام — мир\n#арабский"}
```

Другой вариант — без загрузки в GitHub: перешлите старые ролики в отдельный приватный
Telegram-канал-хранилище и впишите его username/ссылку в секрет `TG_OLD_SOURCE`.
Ролики берутся оттуда по порядку, подпись — из текста сообщения.
Публикуйте только свои собственные ролики.
