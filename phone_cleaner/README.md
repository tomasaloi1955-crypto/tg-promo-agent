# Агент-уборщик для телефона (Android)

Работает прямо на телефоне в приложении **Termux**, без компьютера и без облака.
Раз в неделю сам находит и убирает мусор — в галерее и не только — и присылает
отчёт уведомлением (и, по желанию, в Telegram).

## Что он убирает

| Что | Правило по умолчанию |
|---|---|
| Дубликаты фото, видео, документов | одинаковые по содержимому (имя не важно); оставляется оригинал, в приоритете `DCIM/Camera` |
| Скриншоты | старше 30 дней |
| Медиа WhatsApp / Telegram / Viber | картинки, видео, голосовые, документы старше 60 дней |
| Загрузки | `.apk` старше 7 дней, недокачанные файлы (`.crdownload`, `.part`…) |
| Кэш миниатюр галереи | `.thumbnails` — Android пересоздаст сам |
| Пустые папки | в DCIM, Pictures, Download, Documents, Movies, Music |
| Большие файлы > 100 МБ | **не удаляются** — только список в отчёте, решаете сами |

Все сроки, папки и правила меняются в `config.json` (создаётся при первом запуске).
Папки из списка `"protect"` агент не трогает никогда — впишите туда всё ценное.

## Безопасность

* Первый запуск — **только отчёт**, ничего не удаляется.
* Ничего не стирается сразу: файлы уходят в корзину `.PhoneCleanerTrash`
  (галерея её не показывает) и окончательно удаляются через 30 дней.
* `python cleaner.py restore` возвращает всё из последней уборки на свои места.

## Установка (5 минут)

1. Поставьте из **F-Droid** (не из Play Market — там старые версии):
   **Termux** и **Termux:API**.
2. Откройте Termux и выполните:
   ```
   pkg install -y git
   git clone https://github.com/tomasaloi1955-crypto/tg-promo-agent
   bash tg-promo-agent/phone_cleaner/setup.sh
   ```
   Когда спросят доступ к файлам — «Разрешить».
3. Посмотрите, что будет удалено:
   ```
   python tg-promo-agent/phone_cleaner/cleaner.py
   ```
4. Если всё устраивает — уберите:
   ```
   python tg-promo-agent/phone_cleaner/cleaner.py --apply
   ```
   Дальше уборка запускается сама раз в неделю (когда батарея не разряжена).

Отчёт в Telegram (необязательно): создайте файл `~/.phone_cleaner.env`:
```
BOT_TOKEN=токен_бота
OWNER_ID=ваш_telegram_id
```

## Команды

```
python cleaner.py               отчёт без удаления
python cleaner.py --apply       уборка (в корзину)
python cleaner.py restore       вернуть последнюю уборку
python cleaner.py restore ID    вернуть конкретную уборку (ID = имя папки в корзине)
python cleaner.py purge         сразу очистить корзину и освободить место
```

## Чего агент не может

Android не даёт обычным приложениям (без root) чистить кэш других приложений
и папки `Android/data/*`. Для этого: **Настройки → Хранилище** или **Files by Google**.
На iPhone такой агент невозможен — iOS не даёт доступа к файлам галереи.
