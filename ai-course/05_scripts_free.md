# 05 · Сценарии бесплатного интенсива (3 урока)

Формат: запись экрана + голос (лицо по желанию), без музыки. 15–20 минут на урок.
Текст написан так, чтобы читать с суфлёра. В [квадратных скобках] то, что
показываете на экране. Говорите на «вы», спокойно, как подруге-коллеге.

Инструменты интенсива бесплатные:
- **Claude.ai** или **ChatGPT**: пишут код. Если ни один не открывается, подойдёт DeepSeek.
- **Python 3.12** и **Cursor** (или VS Code): запускают код на компьютере.
- **Render.com** и **GitHub**: держат бота в интернете.
- **Google Таблицы**: сюда приходят заявки.

## Урок 1 · ИИ-помощник, который пишет код (≈15 мин)

**[0:00 · заставка `track_2.png`, 3 сек]**

Ассаляму алейкум! Это интенсив Нейропотока, и за три вечера мы сделаем вашего
собственного Telegram-бота. Бот будет принимать заявки от клиентов, присылать их вам и
работать сам, даже когда компьютер выключен.

Я сразу скажу самое важное: программировать мы не будем. Код будет писать нейросеть. Ваша
задача — объяснить ей, что нужно. Вот этому навыку, ставить задачу ИИ, мы и учимся.
Сейчас он стоит дороже, чем умение писать код руками.

**[0:50 · показываете готового бота на телефоне: /start → имя → телефон → уведомление]**

Вот что у нас получится. Клиент нажимает «Старт», бот спрашивает имя и телефон, а
вам в личку приходит: «Новая заявка: Айгерим, +7…». Плюс строчка в таблице.
Программист за такого бота возьмёт от 10 до 30 тысяч рублей. Вы сделаете его за три вечера.

**[1:40 · раздел 1: какую нейросеть взять]**

Код хорошо пишут три нейросети: Claude, ChatGPT и Gemini. Я покажу на Claude, у меня он
пишет код аккуратнее всех. Но всё, что я делаю, работает и в ChatGPT. Если у вас ничего
из этого не открывается, возьмите DeepSeek: он бесплатный и с кодом справляется.

[открываете claude.ai, регистрация через Google — 20 секунд]

**[3:00 · раздел 2: как ставить задачу]**

Самая частая ошибка — написать нейросети «сделай мне бота». Она сделает, но не того.
Представьте, что вы наняли нового сотрудника. Вы же не скажете ему «сделай работу».
Вы объясните, кто он, что нужно, в каком виде и как проверить результат.

У промпта для кода пять частей. Запишите или скачайте шаблон под видео:

1. **Кто ты:** «Ты — опытный Python-разработчик, объясняешь новичку».
2. **Что делаем:** «Telegram-бот для приёма заявок».
3. **Как работает, по шагам:** «Пользователь нажимает старт → бот здоровается → спрашивает
   имя → спрашивает телефон кнопкой “Поделиться контактом” → благодарит → присылает
   заявку админу».
4. **Ограничения:** «Библиотека aiogram 3, один файл main.py, токен и id админа —
   из переменных окружения, тексты — в начале файла».
5. **Формат ответа:** «Дай полный код и пошаговую инструкцию запуска для человека,
   который никогда не программировал».

[показываете шаблон на экране]

Главный секрет: шаг 3. Чем подробнее вы опишете путь пользователя, тем точнее будет бот.
Код за вас напишут, а продумать путь клиента можете только вы.

**[7:00 · раздел 3: создаём бота в BotFather]**

Теперь создадим самого бота в Telegram. Это делается без кода.

[экран телефона/Telegram Desktop]
Находим @BotFather, именно с синей галочкой. Пишем /newbot. Он спрашивает
имя, это то, что видят люди, например «Запись к Айгерим». Потом username, он должен
заканчиваться на bot, например aigerim_zapis_bot.

BotFather присылает **токен**, длинную строку с двоеточием. Это ключ от вашего бота.
Никому его не показывайте и никуда не публикуйте: с токеном любой может управлять ботом.
Сохраните его в заметках.

[/setuserpic — ставим аватар, /setdescription — описание]

Сразу поставьте аватарку и описание, так бот выглядит живым.

**[10:00 · раздел 4: узнаём свой id]**

Боту нужно знать, кому присылать заявки, то есть вам. Для этого нужен ваш Telegram id.
Напишите боту @userinfobot, он ответит числом. Его тоже сохраните.

**[11:00 · раздел 5: отправляем промпт]**

[вставляете шаблон в Claude, заполняете, отправляете]

Отправляем. Смотрите, нейросеть пишет код и объясняет, что он делает. Сегодня его
запускать не будем, это завтра. Сегодня просто прочитайте объяснение. Не страшно, если
половина непонятна. Задайте ей вопрос: «Объясни эту строчку как пятилетнему ребёнку».
Нейросеть никогда не устаёт от вопросов.

**[13:00 · задание]**

Задание на сегодня, на 10 минут:
1. Создайте бота в BotFather и сохраните токен.
2. Узнайте свой id.
3. Заполните шаблон под **свою** задачу: запись к мастеру, заявки на товар, вопросы
   по курсу, что угодно. Отправьте его в нейросеть.
4. Пришлите @имя вашего бота сюда, в бота интенсива, и нажмите «Сделала задание».

Завтра этот код заработает. До встречи!

**[14:30 · конечная заставка]**

## Урок 2 · Собираем бота с ИИ (≈20 мин)

**[0:00]**

Ассаляму алейкум! Вчера у нас появились бот в BotFather и код от нейросети. Сегодня
этот бот ответит вам по-настоящему.

**[0:30 · установка]**

Нужны две программы, обе бесплатные.
**Python** — язык, на котором написан бот. [python.org → Downloads → установить]
Важно для Windows: на первом экране установки поставьте галочку **«Add Python to PATH»**.
Это самая частая ошибка у новичков, поэтому сразу её отмечу.

**Cursor** — редактор, в который встроен ИИ. [cursor.com → скачать]
Можно и VS Code, но в Cursor ИИ видит ваш код и правит его сам.

**[4:00 · создаём проект]**

[создаём папку `my-bot` на рабочем столе → открываем её в Cursor]
Создаём файл `main.py` и вставляем код, который вчера написала нейросеть.
Потом создаём файл `.env` и пишем туда две строки:
```
BOT_TOKEN=ваш токен
ADMIN_ID=ваш id
```
Файл `.env` — это сейф для секретов. Код берёт токен отсюда, и токен не
попадает в код.

**[6:30 · запуск]**

[Terminal → New Terminal]
Это терминал. Пугаться не нужно, здесь мы будем только вставлять команды.
Первая команда устанавливает библиотеки, которые указала нейросеть:
```
pip install aiogram python-dotenv
```
Вторая запускает бота:
```
python main.py
```
[идём в Telegram → /start → проходим путь → приходит заявка]

Вот, заявка пришла. Ваш первый бот работает! Можете сделать скрин, вы это заслужили 🙂

**[10:00 · если ошибка — самое важное в уроке]**

Если у вас красный текст, это нормально. Ошибки бывают у всех, у программистов
каждый день. Отличие в том, что программист умеет с ними работать. Схема простая:

1. Скопируйте **весь** красный текст.
2. Вставьте его в нейросеть со словами: «Я запустила код, вот ошибка. Объясни, в чём
   дело, и дай исправленный код целиком».
3. Замените код и запустите снова.

[показываете вживую: убираете строку из .env → ошибка → в чат Cursor → исправление]

В Cursor ещё проще: выделяете ошибку и нажимаете «Add to chat». ИИ сам поправит файл,
а вы нажимаете «Accept». В этом и есть вайбкодинг: вы управляете, а ИИ делает.

**[14:00 · дорабатываем]**

Теперь сделаем бота своим. Пишем в чат Cursor:
«Добавь после телефона вопрос “Какая услуга нужна?” с тремя кнопками: маникюр,
педикюр, покрытие. Ответ тоже пришли админу».
[Accept → перезапуск: Ctrl+C, python main.py → проверяем]

Каждую доработку просите отдельно, по одной. Если попросить десять изменений сразу,
нейросеть запутается.

**[17:00 · задание]**

Задание:
1. Запустите бота и оставьте в нём заявку сами себе.
2. Добавьте одну доработку, свою.
3. Нажмите «Сделала задание». Если застряли, пришлите скрин ошибки в чат участников.

Пока бот работает, только когда включён ваш компьютер. Завтра отправим его в интернет,
и он будет работать круглосуточно. До завтра!

## Урок 3 · Бот работает сам, 24/7 (≈20 мин)

**[0:00]**

Ассаляму алейкум! Финальный вечер. Сегодня бот переезжает с вашего компьютера в
интернет, а заявки начинают падать в Google Таблицу.

**[0:30 · таблица]**

Начнём с таблицы, это самое приятное.
[создаём Google Таблицу «Заявки», строка заголовков: Дата | Имя | Телефон | Услуга]
[Расширения → Apps Script]
Просим нейросеть:
«Напиши Google Apps Script с функцией doPost: принимает JSON с полями name, phone,
service и добавляет строку в первый лист с текущей датой. И объясни, как опубликовать его
как веб-приложение».
[вставляем → Начать развёртывание → Веб-приложение → Доступ: все → копируем URL]

Получилась ссылка, по которой бот будет «стучаться» в таблицу. Добавляем её в `.env`
строкой `SHEET_URL=…` и пишем в Cursor:
«После заявки отправляй её POST-запросом в JSON на адрес из SHEET_URL».
[перезапуск → заявка → строчка появилась в таблице]

**[6:00 · GitHub]**

Чтобы бот жил в интернете, его код должен лежать в интернете. Для этого есть GitHub.
[github.com → регистрация → New repository → Private]
Важно: репозиторий **закрытый (Private)**. Файл `.env` с токеном загружать **нельзя**.
Попросите Cursor: «Создай .gitignore, чтобы .env не попал в git, и файл
requirements.txt». Потом через кнопку Source Control в Cursor загружаем проект на GitHub.

**[9:00 · Render]**

[render.com → вход через GitHub → New → Web Service → выбрать репозиторий]
Render — сервис, который запускает ваш код у себя. Бесплатный тариф засыпает, когда им
никто не пользуется, но проснётся сам, как только боту напишут. Первое сообщение после
сна идёт секунд 30–50, дальше бот отвечает быстро. Для старта этого достаточно.

Чтобы бот просыпался сам, ему нужен режим webhook вместо обычного опроса. Просим Cursor:
«Переделай бота на webhook для Render: aiohttp-сервер на порту из PORT, адрес вебхука
из RENDER_EXTERNAL_URL, установка вебхука при старте».
[Start command: `python main.py`]
[Environment → добавляем BOT_TOKEN, ADMIN_ID, SHEET_URL — те же, что в .env]
[Deploy → ждём зелёное Live]

**[14:00 · проверка]**

Выключаем бота на компьютере, закрываем Cursor и пишем боту с телефона.
[заявка приходит в личку + строка в таблице]

Готово! Бот работает сам: ночью, в выходные и пока вы спите.

**[15:30 · итог и мостик к курсу]**

За три вечера вы научились ставить задачу нейросети, собрали бота, научились
разбираться с ошибками и выложили его в интернет. Ещё и связали с таблицей, а это уже
автоматизация.

Это был один маленький проект из одного потока. В Нейропотоке их три:
ИИ-ассистент, чтобы нейросети делали вашу ежедневную работу; Вайбкодинг, где
боты с оплатой, сайты и мини-приложения; Автоматизация, где заявки, оплаты и
рассылки идут сами.

Сегодня в 20:30 бот пришлёт короткое видео: что будет на курсе и как туда попасть
по ранней цене. А пока отправьте ссылку на своего бота в бота интенсива. Я лично
посмотрю, что у вас получилось. Ма ша Аллах, вы молодец!
