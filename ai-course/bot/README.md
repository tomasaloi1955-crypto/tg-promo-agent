# Бот воронки «Нейропоток»

Бот работает так: реклама приводит человека в бота, он отвечает на 2 вопроса и
получает бесплатный мини-интенсив (3 урока, по одному в день). Потом бот показывает
итоги и видео-презентацию курса и 4 дня продаёт. После оплаты в Tribute он сам
выдаёт одноразовые ссылки в закрытые каналы курса.

Тексты для сестёр (на «ты», женский род), оффер — заработок на своих ботах.
Устроен по образцу `sister-bot`, но проще: здесь нет клуба по подписке, анкеты
о здоровье и удаления видео. Зато есть 5 тарифов, разделение на раннюю и обычную
цену и личные вопросы участников, которые бот пересылает вам.

## Как идёт воронка (по времени участника)

| День | Что приходит |
|---|---|
| 1 | `/start` → 2 вопроса + время урока → приветствие, чат участников, **урок 1 сразу** |
| 2 | 13:00 — отзывы участников (только одобренные вами) · 19:00 (или 11:00) — урок 2 |
| 3 | 17:00 — напоминание, если задание 2 не отмечено · 19:00 — урок 3 · 20:00 — «Как вам интенсив?» · 21:00 — итоги + видео-презентация курса |
| 4 | 13:00 — курс и тарифы с кнопками оплаты |
| 5 | 13:00 — ответы на вопросы |
| 6 | 13:00 — «ранняя цена до завтрашней полуночи» |
| 7 | 13:00 — последний день ранней цены |
| 10, 14, 21 | 13:00 — полезное сообщение и кнопка курса (есть кнопка отписки) |
| дальше | раз в 2 недели короткий совет |

- Ранняя цена у каждого своя: она действует до конца **7-го дня его воронки**
  (`EARLY_LAST_DAY`). Потом кнопки ведут на товары по обычной цене (`TRIBUTE_LINK_*_LATE`).
- Если урок не загружен, бот его ждёт. В 21:00 участник один раз получает
  «урок задерживается», а сам урок придёт, как только вы его загрузите (до конца
  следующего дня). Утром и вечером бот напоминает вам, что нужно загрузить.
- Купившим перестают приходить продажи и презентация. Уроки интенсива продолжают приходить.
- После 22:00 бот ничего не шлёт.
- Всё, что человек пишет боту (вопрос, ссылку на своего бота, скрин ошибки),
  приходит вам. Ответить можно командой `/reply id текст`.

Расписание задано в начале `app/funnel.py`, тексты в `app/texts.py`.

## Тарифы

| Код | Тариф | Доступ |
|---|---|---|
| `t1` / `t2` / `t3` / `t4` | один поток (ИИ-ассистент / Вайбкодинг / Автоматизация / Маркетинг) | канал этого потока |
| `full` | Нейропоток целиком | все 4 канала потоков |
| `mentor` | с наставницей | 4 канала + чат наставницы |

Если у вас пока **один** закрытый канал на весь курс, заполните только `COURSE_CHAT_ID`.
Все тарифы получат ссылку в него.

## Админка (`/admin`)

`/stats` · `/upload 1` (уроки 1–3; `/upload 4` для видео-презентации) · `/lessons` · `/show 2` ·
`/broadcast` · `/reviews` · `/reply id текст` · `/list` · `/who id` · `/grant id full` ·
`/links id` · `/export` · `/tick` · `/cancel`

Урок загружается так: отправьте `/upload 1`, затем видео. Подпись к видео станет текстом
урока, туда же впишите задание. Видео защищено от пересылки.

## Запуск

### 1. Telegram
1. В @BotFather создайте бота. Имя, описание и аватар взяты из `../03_bot_funnel.md`
   и `../covers/avatar.png`.
2. Создайте закрытые каналы курса: по одному на поток (или один общий) и, если
   нужно, чат наставника. Добавьте туда бота администратором с правом
   «Пригласительные ссылки». Чтобы узнать id канала (вид `-100…`), перешлите
   сообщение из него в @userinfobot.
3. Чат участников интенсива: создайте обычную ссылку-приглашение и впишите её в `FREE_CHAT_LINK`.
4. Канал Halal AI | Freya: добавьте бота админом с правом «Добавлять подписчиков». Тогда
   по ссылкам-приглашениям «с заявкой» бот сам напишет новому подписчику и поведёт его в
   интенсив. Метка источника берётся из названия ссылки.

### 2. База
Новый проект в [neon.tech](https://neon.tech). Скопируйте строку подключения в `DATABASE_URL`.
**Нужна отдельная база, не база sister-bot.** Таблицы бот создаст сам.

### 3. Render
**New → Web Service** → репозиторий `tg-promo-agent`:
- **Root Directory**: `ai-course/bot`
- **Build Command**: `pip install -r requirements.txt`
- **Start Command**: `python -m app.main`
- **Environment**: переменные из `.env.example`. Обязательные: `BOT_TOKEN`, `DATABASE_URL`,
  `WEBHOOK_SECRET`, `TICK_KEY`, `ADMIN_IDS`, а также `PYTHON_VERSION` = `3.11.9`.

После деплоя откройте `https://ВАШ-СЕРВИС.onrender.com/health`, там должно быть `ok`.

> ⚠️ На бесплатном тарифе Render 750 часов в месяц на **весь аккаунт**. В этом же
> аккаунте уже работают sister-bot и сайт школы. Третий сервис, который будят
> каждый час, может исчерпать лимит, и тогда Render остановит все сервисы. На время
> рекламы лучше перевести этого бота на платный Starter (~7 $/мес) или завести
> отдельный аккаунт Render. Бонус платного тарифа: бот не засыпает и отвечает сразу.

### 4. Будильник
В GitHub-репозитории `tg-promo-agent` откройте **Settings → Secrets and variables → Actions** и
создайте секрет `NEURO_TICK_URL` = `https://ВАШ-СЕРВИС.onrender.com/tick?key=ВАШ_TICK_KEY`.
Будильник лежит в `.github/workflows/neuro_tick.yml` и срабатывает раз в час. GitHub
иногда сильно опаздывает с расписанием. Надёжнее cron-job.org: тот же адрес плюс
`&bg=1`, расписание **Every hour**.

### 5. Оплата (Tribute)
1. Заведите в Tribute **цифровые товары** (разовая оплата, не подписка): по товару на
   каждый тариф по ранней цене. По желанию добавьте второй товар по обычной цене.
   Ссылки впишите в `TRIBUTE_LINK_<ТАРИФ>` и `TRIBUTE_LINK_<ТАРИФ>_LATE`.
2. Вебхук. **Если аккаунт Tribute общий с sister-bot**, адрес уведомлений уже ведёт на
   sister-bot. Ничего не меняйте в Tribute: в sister-bot для каждого товара курса выполните
   `/route <id товара> https://ВАШ-СЕРВИС.onrender.com/tribute`. sister-bot перешлёт
   уведомление с той же подписью, а здесь впишите тот же `TRIBUTE_API_KEY`.
   Если аккаунт отдельный, укажите в Tribute адрес `https://ВАШ-СЕРВИС.onrender.com/tribute`.
3. Id товаров впишите в `TRIBUTE_PRODUCT_IDS_<ТАРИФ>` (ранний и обычный через запятую).
   Если id неизвестны, сделайте тестовую покупку: бот пришлёт «незнакомый товар, id …».
4. Запасной путь: кнопка «Я оплатил(а)». Вам придёт заявка с кнопками «выдать доступ»
   и «оплаты нет».

### 6. Проверка перед рекламой
1. `/upload 1`, `/upload 2`, `/upload 3`, `/upload 4`, затем `/lessons`: везде должно быть 🎬.
2. Пройдите воронку сами со ссылкой `t.me/<бот>?start=src_test`.
3. `/grant <ваш id> full`: проверьте, что пришли ссылки во все каналы.
4. `/stats`: метка `test` должна быть видна.

## Локально

```
pip install -r requirements.txt
cp .env.example .env        # вписать BOT_TOKEN, DATABASE_URL, ADMIN_IDS
python -m app.main --polling
python -m pytest tests      # тесты расписания
```
