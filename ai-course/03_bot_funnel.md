# 03 · Бот воронки «Нейропоток»

Бот — копия `sister-bot` (та же логика: анкета → уроки по дням → прогрев → продажа →
оплата Tribute → одноразовая ссылка в закрытый канал). Меняются тексты и расписание.
Ниже тексты сгруппированы по ключам `app/texts.py`, чтобы их было легко перенести.

## @BotFather

- Имя: `Нейропоток · ИИ и вайбкодинг`
- Username: `neuropotok_bot` (запасные: `neuropotok_ai_bot`, `freya_neuro_bot`)
- Аватар: `covers/avatar.png`
- Description (до 512 символов, видно до /start):
  ```
  Бесплатный мини-интенсив «Свой Telegram-бот без программиста — за 3 вечера».
  3 коротких урока, задания и готовый бот в конце. Без опыта в программировании —
  код пишет ИИ, вы ставите задачу.
  Нажмите «Старт» 👇
  ```
- About (до 120): `ИИ, вайбкодинг и автоматизация. Бесплатный интенсив: свой бот за 3 вечера.`

## Расписание (`app/funnel.py`)

```python
WORKOUT_DAYS = {1: 1, 2: 2, 3: 3}   # уроки каждый день, без дней отдыха
CHECKIN_DAYS = (3,)                 # «Как вам интенсив?» вечером дня 3
NUDGE_DAYS = {3: 2}                 # днём 3 — если урок 2 не отмечен
WARM_DAYS = {2: "warm_reviews", 3: "warm_stats"}
SALE_DAYS = (4, 5, 6, 7)            # презентация+тарифы, возражения, 24 часа, последний шанс
POST_DAYS = (10, 14, 21)
```
Время: урок — 19:00 (или 11:00 по выбору), прогрев и продажа — 13:00, тихий час — 22:00.
В `sale` нужен четвёртый текст (`SALE_24H`) — добавить ключ `sale:6`.
